# 📄 마크다운 뷰어 (Mobile Markdown Viewer)

빌드 과정이나 서버 없이, 정적 파일만으로 동작하는 **모바일 친화적 마크다운 뷰어/편집기**입니다.
휴대폰 브라우저에서 바로 열어 쓰거나 홈 화면에 앱처럼 설치할 수 있습니다.

## 주요 기능

- **편집 / 미리보기 탭 전환** — 좁은 화면(모바일)에서는 탭으로 전환, 넓은 화면(태블릿/PC)에서는 자동으로 좌우 분할 뷰
- **GFM 마크다운 지원** — 표, 체크리스트, 코드 블록, 취소선 등 (`marked` 사용, `DOMPurify`로 XSS 방지 sanitize)
- **파일 열기** — 기기에서 `.md`/`.txt` 파일 선택, 데스크톱에서는 드래그 앤 드롭도 지원
- **"공유하기"로 받기 (Web Share Target)** — 안드로이드 등에서 파일 관리자·다른 앱의 "공유" 메뉴로 이 뷰어를 선택하면 바로 열람 가능 (PWA로 설치한 경우)
- **저장** — 편집한 내용을 `.md` 파일로 다운로드
- **목차(TOC)** — 제목을 자동 추출해 사이드 드로어에서 탭하면 해당 위치로 이동
- **글자 크기 조절 / 다크·라이트 테마** — 시스템 설정을 따르되 수동 전환 가능, 선택값은 기기에 저장
- **자동 저장** — 입력 중인 내용을 로컬에 자동 저장, 새로고침해도 유지
- **오프라인 지원(PWA)** — 서비스 워커가 정적 자산을 캐시해 네트워크 없이도 실행

## 사용 방법

정적 파일이므로 별도 빌드 없이 아무 정적 웹 서버로 제공하면 됩니다.

```bash
# 로컬에서 확인
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

GitHub Pages, Netlify, Vercel, S3 등 정적 호스팅 어디에 올려도 그대로 동작합니다.
경로는 모두 상대 경로로 작성되어 있어 저장소를 프로젝트 페이지(`/저장소이름/` 같은 하위 경로)로 배포해도 문제없습니다.

모바일에서는 브라우저 메뉴의 "홈 화면에 추가"를 사용하면 앱처럼 아이콘이 설치되고,
설치 후에는 다른 앱의 "공유" 메뉴에서 이 뷰어를 선택해 `.md` 파일이나 텍스트를 바로 열 수 있습니다.

## 폴더 구조

```
index.html            앱 진입점
css/style.css         반응형(모바일 퍼스트) 스타일, 라이트/다크 테마
js/app.js             렌더링, 파일 열기/저장, TOC, 테마, 공유 수신 등 앱 로직
sw.js                 서비스 워커 (오프라인 캐시 + Web Share Target 처리)
manifest.webmanifest  PWA 매니페스트 (설치, 아이콘, share_target)
icons/                앱 아이콘 (SVG)
vendor/               외부 라이브러리 (marked, DOMPurify) — 오프라인 동작을 위해 로컬에 포함
```

## 사용한 오픈소스

- [marked](https://github.com/markedjs/marked) (MIT License) — 마크다운 → HTML 변환
- [DOMPurify](https://github.com/cure53/DOMPurify) (Apache-2.0 / MPL-2.0) — 렌더링 결과 sanitize (XSS 방지)

각 파일 상단에 원본 라이선스 헤더가 그대로 포함되어 있습니다.
