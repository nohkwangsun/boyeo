# 📄 마크다운 뷰어 (Mobile Markdown Viewer)

정적 파일만으로 동작하는 **마크다운 뷰어**입니다. 웹·단일 HTML 파일·데스크탑 앱·안드로이드 앱으로 쓸 수 있습니다.
휴대폰 브라우저에서 바로 열어 쓰거나 홈 화면에 앱처럼 설치할 수 있습니다.

## 설계 원칙

**주인공은 본문이다.** 앱을 열면 곧바로 읽기 화면이고, 상단바는 48px 한 줄(아이콘 2개)만 남긴다.
아래로 읽어 내려가면 상단바도 사라진다. 편집은 뷰어를 가리지 않는 별도 모드로 분리했고,
아이콘은 전부 본문 색을 상속하는 단색 라인 아이콘이라 화면이 산만해지지 않는다.

## 주요 기능

- **읽기 우선 화면** — 실행 즉시 뷰어. 스크롤을 내리면 상단바가 숨고, 올리면 다시 나타난다
- **블록별 읽어주기(TTS)** — 문단/제목/코드블록/표 등 블록마다 오른쪽에 작은 스피커 버튼이 있어 그 부분만 들을 수 있다. 메뉴의 "전체 듣기"로 문서 전체를 들을 수도 있고, 읽기 속도(0.75~1.5×)도 조절 가능. 브라우저 내장 음성(Web Speech API)이라 서버 없이도 동작하며, 한국어 문서는 자동으로 한국어 음성을 우선 사용한다. 한/영이 섞인 문장은 구간을 나눠 각각 맞는 언어로 읽어 발음이 어색하지 않다
- **반복 재생** — 재생 바의 반복(🔁) 버튼을 켜두면 다 읽고 난 뒤 같은 내용을 계속 반복한다. 영어 문장 섀도잉 연습처럼 같은 문장을 여러 번 듣고 싶을 때 쓰면 된다. 켠 채로 다른 블록을 누르면 그 블록이 반복 대상이 된다
- **GFM 마크다운** — 표, 체크리스트, 코드 블록, 인용 등 (`marked` 렌더링 + `DOMPurify` sanitize로 XSS 차단)
- **파일 열기** — 기기의 `.md`/`.txt` 선택, 데스크톱에서는 드래그 앤 드롭
- **목차** — 제목을 자동 추출, 탭하면 해당 위치로 이동
- **편집 모드** — 메뉴에서 진입하는 별도 전체 화면. "완료"를 누르면 뷰어로 돌아온다
- **글자 크기 / 테마** — 자동·밝게·어둡게 3단 선택, 설정은 기기에 저장
- **자동 저장** — 보던 문서를 로컬에 저장해 다시 열어도 그대로
- **한글 조판** — `word-break: keep-all` 로 단어 중간에서 줄이 끊기지 않는다
- **"공유하기"로 받기 (Web Share Target)** — 다른 앱의 공유 메뉴에서 바로 열기 (PWA 설치 시)
- **오프라인 지원(PWA)** — 서비스 워커가 정적 자산을 캐시

## 사용 방법

### 방법 1. 단일 파일 (서버 없이 사용) — `markdown-viewer.html`

`markdown-viewer.html` 하나만 내려받아 휴대폰에 저장한 뒤 브라우저로 열면 바로 동작합니다.
CSS·JS·라이브러리가 모두 이 파일 안에 들어 있어서 **인터넷도, 서버도 필요 없습니다.**

- ✅ 문서 읽기, 표·체크리스트·코드블록, 목차, 다크모드, 글자 크기, 자동 저장, 파일 열기·저장, 편집
- ❌ 홈 화면 설치(PWA), 오프라인 캐시, 다른 앱에서 "공유"로 받기
  → 이 세 가지는 브라우저가 서비스 워커를 HTTPS에서만 허용하기 때문에 `file://`에서는 쓸 수 없습니다. 방법 2를 쓰세요.

이 파일은 `index.html` 과 그 자산들로부터 생성됩니다. 원본을 수정한 뒤에는 다시 만들어 주세요.

```bash
node build-standalone.js   # → markdown-viewer.html
```

### 방법 2. 정적 호스팅 (전체 기능)

정적 파일이므로 별도 빌드 없이 아무 정적 웹 서버로 제공하면 됩니다.

```bash
# 로컬에서 확인
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

GitHub Pages, Netlify, Vercel, S3 등 정적 호스팅 어디에 올려도 그대로 동작합니다.
경로는 모두 상대 경로로 작성되어 있어 저장소를 프로젝트 페이지(`/저장소이름/` 같은 하위 경로)로 배포해도 문제없습니다.

모바일에서는 브라우저 메뉴의 "홈 화면에 추가"를 사용하면 앱처럼 아이콘이 설치되고,
설치 후에는 다른 앱의 "공유" 메뉴에서 이 뷰어를 선택해 `.md` 파일이나 텍스트를 바로 열 수 있습니다.

## 폴더 구조

```
index.html             앱 진입점
css/style.css          반응형(모바일 퍼스트) 스타일, 라이트/다크 테마
js/app.js              렌더링, 파일 열기/저장, TOC, 테마, 공유 수신 등 앱 로직
sw.js                  서비스 워커 (오프라인 캐시 + Web Share Target 처리)
manifest.webmanifest   PWA 매니페스트 (설치, 아이콘, share_target)
icons/                 앱 아이콘 (SVG)
vendor/                외부 라이브러리 (marked, DOMPurify) — 오프라인 동작을 위해 로컬에 포함

build-standalone.js    위 파일들을 하나로 합치는 빌드 스크립트
markdown-viewer.html   ↑ 로 생성된 단일 파일 배포본 (직접 수정하지 마세요)

src-tauri/             데스크탑 앱(Tauri) — Rust 셸, 메뉴/파일연결/파일입출력
android/               안드로이드 앱(Capacitor) 프로젝트
build-www.js           웹 자산을 네이티브 앱용 www/ 로 모으는 스크립트
js/native-bridge.js    웹앱↔네이티브(Tauri/Electron) 연결 다리
capacitor.config.json  Capacitor 설정
package.json           앱 빌드 스크립트
```

## 앱으로 쓰기 (데스크탑 / 모바일)

같은 웹앱 코드를 데스크탑(Tauri)과 안드로이드(Capacitor) 앱으로 감쌌다.
소스는 하나이므로 `index.html`/`css`/`js` 를 고치면 웹·단일파일·데스크탑·모바일에 모두 반영된다.

데스크탑은 Electron 대신 **Tauri** 를 쓴다. Electron 은 Chromium 을 통째로
끼워 넣어 설치 파일이 160MB를 넘었는데(실제 앱 코드는 0.2MB), Tauri 는
운영체제에 이미 있는 웹뷰를 쓰기 때문에 10MB 안팎으로 끝난다.

### 완성된 설치 파일 받기

`Actions → 앱 빌드 → Run workflow` 를 누르면 GitHub 이 각 운영체제에서 빌드해 준다.
끝나면 실행 결과 페이지 아래 Artifacts 에서 받는다.

| 플랫폼 | 산출물 |
|---|---|
| Windows | `.exe` (NSIS 설치 파일), `.msi` |
| macOS | `.dmg` (Intel/Apple Silicon 통합) |
| Linux | `.AppImage`, `.deb` |
| Android | `.apk` (디버그 서명) |

윈도우는 WebView2(엣지) 를 쓴다. 윈도우 10/11 에는 기본 포함되어 있어
따로 설치할 것이 없다.

`v1.0.0` 처럼 `v` 로 시작하는 태그를 밀면 릴리스가 만들어지고 모든 파일이 자동 첨부된다.

> 코드 서명 인증서가 없어 서명되지 않은 앱이다. 처음 실행할 때
> Windows 는 "Windows의 PC 보호" → *추가 정보 → 실행*,
> macOS 는 앱을 *우클릭 → 열기* 로 한 번만 허용해 주면 된다.
> 안드로이드는 "출처를 알 수 없는 앱 설치"를 허용해야 APK 가 설치된다.

### 데스크탑 앱에서 늘어나는 것

- **.md 파일 연결** — 파일을 더블클릭하면 이 앱으로 열린다
- **네이티브 메뉴 / 단축키** — `Ctrl(⌘)+O` 로 열기, 확대·축소, 전체 화면
- **창 크기·위치 기억** — 다음에 켜면 그대로
- **외부 링크는 기본 브라우저로** — 문서 안 링크를 눌러도 앱이 다른 페이지로 가버리지 않는다

### 안드로이드 앱에서 늘어나는 것

- **.md 파일 연결** — 파일 관리자에서 마크다운을 탭하면 앱 목록에 뜬다
- **공유로 받기** — 다른 앱의 "공유" 메뉴로 텍스트·파일을 바로 열 수 있다

### 직접 빌드하기

```bash
npm install

npm run desktop:dev    # 데스크탑 앱 실행 (개발용)
npm run desktop:build  # 현재 OS 용 설치 파일 만들기

npm run mobile:sync    # 웹 자산을 안드로이드 프로젝트로 동기화
cd android && ./gradlew assembleDebug    # APK (Android SDK 필요)
```

데스크탑 빌드에는 [Rust](https://rustup.rs) 가 필요하고, 리눅스에서는
`libwebkit2gtk-4.1-dev` 등 시스템 패키지도 있어야 한다
(자세한 목록은 워크플로의 "리눅스 빌드 의존성" 단계 참고).

설치 파일은 자기 운영체제에서만 만들 수 있다(윈도우 exe 는 윈도우에서).
그래서 위의 GitHub Actions 로 세 OS 를 한 번에 빌드하는 쪽이 편하다.

## 사용한 오픈소스

- [marked](https://github.com/markedjs/marked) (MIT License) — 마크다운 → HTML 변환
- [DOMPurify](https://github.com/cure53/DOMPurify) (Apache-2.0 / MPL-2.0) — 렌더링 결과 sanitize (XSS 방지)

각 파일 상단에 원본 라이선스 헤더가 그대로 포함되어 있습니다.
